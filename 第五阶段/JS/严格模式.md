# 严格模式（use strict）
>[菜鸟教程：严格模式](https://www.runoob.com/js/js-strict.html)
>
> 作用：开启**严格模式**，让JS语法检查更严格，消除JS一些不合理、不安全、晦涩的隐式行为，减少隐性bug，部分代码才能被高级编译器优化。

## 开启严格模式
**写字符串 `"use strict";`**
>
>
><img width="614" height="252" alt="屏幕截图 2026-08-16 092858" src="https://github.com/user-attachments/assets/5bad0019-4888-471a-a633-f573a60d87c4" />
>
>按**shift+ctrl+i**开启调试模式
>
>
><img width="706" height="211" alt="屏幕截图 2026-08-16 092719" src="https://github.com/user-attachments/assets/92890823-b23e-413f-9234-9c146632bc8b" />


1. **全局严格模式**：写在脚本最顶部，整个js文件全部生效
```js
"use strict";
// 下面所有代码都走严格模式
let num = 10;
```

2. **函数内局部严格模式**：只在当前函数内部生效，其他函数不受影响
```js
function test(){
  "use strict";
  // 仅这个函数开启严格模式
}
```

> ⚠️注意：`"use strict"`上面**不能写其他代码**，注释可以，写变量/语句就失效。

## 严格模式主要变化
### 1. 不允许不声明变量直接赋值
>
><img width="706" height="211" alt="屏幕截图 2026-08-16 092719" src="https://github.com/user-attachments/assets/22bdff01-1507-479e-8cc5-d7312ac569ea" />


普通模式：不写`let/var/const`，会自动创建全局变量（隐式全局）
```js
//普通模式
a = 100; 
console.log(a); //可以运行，a变成全局变量
```

严格模式直接**报错**
```js
"use strict";
a = 100; // Uncaught ReferenceError: a is not defined
```
> 必须：`let a =100;`

### 2. 禁止删除变量、函数
普通模式删除变量不会报错，只是无效
严格模式删除变量直接报错
>
><img width="717" height="132" alt="屏幕截图 2026-08-16 093932" src="https://github.com/user-attachments/assets/32b790ef-2962-4012-a50e-c9155c8bad55" />

```js
"use strict"
let x = 10;
delete x; //报错，不能删除变量
```
> 可以删除对象属性：`delete obj.prop` 没问题

### 3. 对象属性不能重名
普通模式对象键重复，后面覆盖前面，不报错
```js
const obj = {
  name:"A",
  name:"B"
}
```
严格模式直接报错。

### 4. 函数参数不允许重名
>
><img width="702" height="169" alt="屏幕截图 2026-08-16 094151" src="https://github.com/user-attachments/assets/5b334f67-9d46-4413-a954-be20c3437e00" />

```js
"use strict";
function fn(a,a){ // 参数两个a，严格模式报错
}
```

### 5. this指向发生改变
普通模式：普通函数直接调用，`this`指向**window全局对象**
严格模式：普通函数直接调用，`this = undefined`
>
><img width="681" height="129" alt="屏幕截图 2026-08-16 094539" src="https://github.com/user-attachments/assets/5983691d-7e09-46e8-ab42-0edb186c2f49" />

```js
"use strict";
function show(){
  console.log(this); // undefined
}
show();
```
> 坑：严格模式普通函数里`this`不能指向window，直接给this赋值会报错。
> 箭头函数不受严格模式这条影响。

### 6. 禁止八进制数字字面量
普通模式可以写`0123`代表八进制
严格模式 `0123`直接报错，要写八进制用 `0o123`
>
><img width="721" height="163" alt="屏幕截图 2026-08-16 094654" src="https://github.com/user-attachments/assets/594f0249-20b0-4606-8068-1b2d68977464" />

```js
"use strict"
let n = 012; // ❌报错
let m = 0o12; // ✅正确八进制写法
```

### 7. 禁止 `eval` 创建变量泄露到外部
普通模式eval里面声明变量会跑到外面作用域，污染全局
严格模式eval内部的变量，只能在eval内部使用。
>
><img width="674" height="145" alt="屏幕截图 2026-08-16 095020" src="https://github.com/user-attachments/assets/3322f59f-00bb-4c66-add8-ae6fc5147871" />

```js
"use strict";
eval("let b=20");
console.log(b); //报错，访问不到eval里面变量
```

### 8. with语句直接禁用
```js
"use strict";
with(obj){} //直接报错，不能使用with
```

### 9. 给只读属性赋值直接报错
普通模式给只读对象属性赋值，静默失败，不报错，很难排查bug
严格模式直接抛出错误。
```js
"use strict";
const obj = {};
Object.defineProperty(obj,"age",{writable:false,value:18})
obj.age = 99; //严格模式直接报错
```

## 严格模式总结表格
| 行为 | 普通模式 | 严格模式 use strict |
|---|---|---|
| 未声明变量直接赋值 | 创建隐式全局变量 | 报错ReferenceError |
| 普通函数直接调用this | this指向window | this = undefined |
| 对象重复属性 | 后面覆盖前面 | 报错 |
| 函数重名参数 | 正常运行 | 报错 |
| delete 删除变量 | 静默失败 | 报错 |
| 八进制0开头数字 | 允许 | 报错，要用0o |
| with语法 | 允许 | 禁止报错 |
| eval变量 | 泄露到外部 | 隔离，不能外部访问 |

## 什么时候用严格模式
1. 写原生JS项目，建议开启，减少隐蔽bug
2. ES6 class类内部**默认开启严格模式**！！
> class里面写的方法，自动处于严格模式，不用手动写`use strict`

```js
class Person{
  fn(){
    //这里自动严格模式
  }
}
```

## 易错坑
1. `"use strict"`是字符串，不是关键字，引号不能丢；
2. 写在函数内只对当前函数生效；
3. class内部自带严格模式，不要再重复写；
4. 严格模式**不会改变箭头函数this规则**。
