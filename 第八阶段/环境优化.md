# 环境优化：阿里npm镜像
> 网站：[npm配置阿里镜像库](https://blog.csdn.net/morecccc/article/details/137785890)
> 
国内访问官方npm源很慢，切换淘宝镜像。
> ⚠️旧淘宝镜像`http://registry.npm.taobao.org`已经废弃，新地址：`https://registry.npmmirror.com`

```bash
# 设置全局镜像
npm config set registry https://registry.npmmirror.com

# 查看当前源
npm config get registry
```

pnpm/yarn同样可以设置镜像源。
