
# package.json 配置规范
[软件配置管理规范完整指南](https://blog.csdn.net/weixin_35755562/article/details/151767764)
```json
{
  "name": "demo-vue",        // 项目名称，不能有大写空格
  "version": "0.0.1",        // 版本号 major.minor.patch
  "scripts": {               // 脚本命令 npm run dev
    "dev": "vite",
    "build": "vite build"
  },
  "dependencies": { },       // 业务运行依赖，上线也要用（vue、axios）
  "devDependencies": { },    // 开发阶段依赖，打包后不需要（vite、eslint）
  "main": "index.js",
  "private": true            // true代表私有项目，不发布到npm仓库
}
```
- `dependencies`：运行依赖，项目跑起来必须要有。
- `devDependencies`：开发依赖，仅本地开发、打包阶段使用，生产环境不需要。
