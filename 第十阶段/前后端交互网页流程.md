# 实操全流程

> 
> 环境：VSCode + Node.js，项目文件夹名字：`demo`
> 文件清单：`server.js`（后端）、`index.html`（前端网页）

## 1.新建项目文件夹

1. 电脑E盘新建文件夹，命名 `demo`
2. VSCode左上角：**文件 → 打开文件夹**，选中`demo`打开> 
> ✔左边资源管理器空白，代表进入项目

## 2.调出VSCode终端



快捷键 `Ctrl + \`\`（Tab上方按键），底部弹出终端面板。 终端路径显示：`PS E:\demo>`

## 3.初始化项目、安装工具包

依次输入下面命令，每输完一条按回车

```
npm init -y
npm install express cors
```

执行完，文件夹自动生成：`package.json`、`node_modules`文件夹。

> 
> 如果出现 `ERR_INVALID_PACKAGE_CONFIG` 报错：删除`package.json`，重新执行上面两行。

## 4.编写后端代码 server.js


1. VSCode新建文件，命名 `server.js`
2. 复制后端全部代码粘贴，按 `Ctrl+S`保存

```
const express = require('express')
const cors = require('cors')
const app = express()

app.use(cors())
app.use(express.json())

app.post('/api/submit', (req, res) => {
    const inputMsg = req.body.msg
    if(!inputMsg){
        return res.json({
            code:400,
            msg:"输入不能为空",
            data:null
        })
    }
    const backResult = `后端收到消息：${inputMsg}。这是后端加工处理后的回复`
    res.json({
        code:200,
        msg:"请求成功",
        data: backResult
    })
})

app.listen(3000, ()=>{
    console.log("✅后端服务启动成功！地址：http://127.0.0.1:3000")
})
```

## 5.编写前端页面 index.html

1. demo文件夹新建文件，命名`index.html`
2. 复制前端全部代码粘贴，`Ctrl+S`保存

```
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>前后端交互演示</title>
    <style>
        .wrap{
            width:520px;
            margin:80px auto;
        }
        textarea{
            width:100%;
            height:110px;
            padding:8px;
            box-sizing: border-box;
        }
        button{
            margin:10px 0;
            padding:7px 18px;
            cursor: pointer;
        }
        .show-box{
            border:1px solid #999;
            padding:12px;
            min-height:90px;
            white-space: pre-wrap;
        }
    </style>
</head>
<body>
<div class="wrap">
    <h3>前端输入，请求后端获取返回结果</h3>
    <textarea id="inp" placeholder="请输入内容"></textarea>
    <br>
    <button id="btn">提交到后端</button>
    <div>后端返回结果：</div>
    <div class="show-box" id="resBox"></div>
</div>

<script>
const inp = document.querySelector('#inp')
const btn = document.querySelector('#btn')
const resBox = document.querySelector('#resBox')

btn.onclick = async function(){
    const content = inp.value.trim()
    if(!content){
        resBox.innerText = "请输入内容！"
        return
    }
    try{
        const resp = await fetch("http://127.0.0.1:3000/api/submit",{
            method:"POST",
            headers:{
                "Content-Type":"application/json"
            },
            body: JSON.stringify({
                msg: content
            })
        })
        const result = await resp.json()
        if(result.code === 200){
            resBox.innerText = result.data
        }else{
            resBox.innerText = `错误：${result.msg}`
        }
    }catch(err){
        resBox.innerText = "❌请求失败，请确认后端已经启动！"
        console.error(err)
    }
}
</script>
</body>
</html>
```

# 数据流转

1. 用户网页输入文字 → JS读取输入框value
2. `JSON.stringify()`把js对象转为字符串
3. fetch发送POST请求传给后端接口
4. `express.json()`解析数据存入`req.body`
5. 后端执行业务逻辑处理文字
6. `res.json()`返回JSON数据给浏览器
7. 前端解析JSON，渲染展示到页面

# 修改代码规则

1. 修改**后端server.js**：终端按`Ctrl+C`停止，重新运行`node server.js`
2. 修改**前端index.html**：保存，浏览器按F5刷新即可

# 常见报错

1. `ERR_INVALID_PACKAGE_CONFIG`：package.json损坏，删除后重新`npm init -y`
2. 请求失败：检查后端是否启动，终端不能关闭
3. node不是内部命令：重新安装Node.js
4. req.body为undefined：确认`server.js`写了`app.use(express.json())`
