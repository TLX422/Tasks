# 前后端交互学习笔记
---
## 一、前后端连接的概念
前端：负责页面展示、用户交互（浏览器页面）；
后端：负责数据存储、业务逻辑处理、权限校验（服务器程序）。

**前后端连接（前后端交互）**：
前端通过网络请求，向后端服务器发送指令；后端接收请求、处理逻辑，返回数据给前端；前端拿到数据渲染页面。
前后端分离模式下，两者代码独立开发，依靠**网络通信**完成数据互通。

## 二、常见前后端连接方式
### 1. 通信协议
#### HTTP / HTTPS（最主流）
- HTTP：超文本传输协议，无状态；浏览器默认支持。
- HTTPS：HTTP + SSL加密，传输数据安全，正式项目统一使用。
- 请求方式：GET（查询数据）、POST（提交数据）、PUT、DELETE等。

#### 补充其他协议
- WebSocket：长连接，双向实时通信；适合聊天、实时通知、数据大屏。
### 2. API（接口）
API（应用程序接口）：后端提供的**数据访问地址**，是前后端约定好的通信入口。
格式示例：
`http://localhost:3000/api/getUser`
- 前后端约定：请求地址、请求方式、传递参数、返回数据格式（一般使用JSON）。
- 数据通用格式 JSON：轻量、JS天然支持，目前行业标准。

### 前端发送请求的常见手段
1. 原生 JavaScript：`XMLHttpRequest`（Ajax）、`fetch`
2. 封装库：axios（Vue/React项目最常用）

## 三、尝试实现前后端连接（简易Demo思路）
### 方案：前端Axios + 简易后端服务
1. 后端（示例：Node.js + Express）搭建接口，提供API地址
```js
// 后端简易接口
app.get('/api/getMsg',(req,res)=>{
  res.json({msg:"前后端通信成功！"})
})
```
2. 前端引入axios，发起网络请求
```js
import axios from 'axios'
axios.get("http://localhost:3000/api/getMsg").then(res=>{
  console.log(res.data.msg)
})
```
### ⚠️常见问题：跨域
浏览器同源策略限制，前端域名、端口与后端不一致会出现**跨域报错**。
解决方案：后端配置CORS跨域允许、开发环境配置代理。

## 四、难点标注
1. **协议与API区分**
协议（HTTP）：通信规则；API：后端提供的具体访问地址。
2. GET与POST使用场景区别
GET用于获取数据，参数拼接在URL；POST用于提交表单、上传数据，参数放在请求体。
3. 跨域原理：浏览器安全策略，不是后端BUG，开发必须了解。
4. JSON作用：前后端统一的数据交换格式。
